Requirements:
owlready-0.3

Running:
python start.py

* Errors in 'Error.txt' file
* IRI must end with ontology filename
  i.e.
    IRI : http://www.semanticweb.org/puhthangmakhupane/ontologies/2024/10/testOntoSeSothoWithPW.owl
    filename: testOntoSeSothoWithPW.owl
* Ontology folder will be the full directly containing the owl file, without the filename, e.g.C:\Users\user1\project\ontology
